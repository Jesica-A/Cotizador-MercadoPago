# Cotizador Mercado Pago

Página simple para calcular el precio de lista a cobrar en Point Smart
a partir del monto en efectivo que se quiere recibir.

Las tasas pueden varias si es un monotributo nuevo o por descuentos a monotributistas (consultar con tu asesor de Mercado Pago)

## Tasas usadas (Córdoba, acreditación al instante, IVA incluido)
- Costo por cobro (crédito): 6,29%
- 3 cuotas: 10,49%
- 6 cuotas: 18,69%
- 9 cuotas: 26,49%
- 12 cuotas: 32,29%
